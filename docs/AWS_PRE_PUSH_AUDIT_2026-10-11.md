## Concrete deployment blockers and proposed fixes

1. **Import-time failures:** `lib/supabase.ts:6–8` throws without public URL/anon key; static imports remain in Navbar, Hero/HipHopHero/BespokeHero, legacy auth/profile and both checkout clients. `lib/server-supabase.ts:7` also throws during module evaluation, even when callers choose RDS. Conditional auth calls do not protect imports. Proposed F9 work: remove dead client imports and replace the remaining auth/data callers before eliminating the module.
2. **Hidden server ENV dependencies:** `lib/catalog-products.ts:753` and `lib/education.ts:47,104` instantiate Supabase before selecting RDS. `app/about/page.tsx:15` returns empty content without Supabase URL even with RDS enabled. Education retains compatibility fallback. Proposed work: make AWS paths independent at initialization and on errors; explicitly decide remaining legacy endpoints rather than silently returning empty content.
3. **Reachable legacy transport:** catalog/taxonomy/navbar/home/editorial/support/About/Bespoke/public CMS, checkout/pricing/profile/orders/payment/webhook/recovery routes retain Supabase branches. `/api/profile` still uses legacy auth. Cron defaults to Supabase RPCs when all new gates are off. Search hits require branch-by-branch review; enabled F2 flags alone do not establish provider independence.
4. **Media without old ENVs:** `media-url.ts:35` rewrites Supabase absolute URLs only for the configured old host; custom R2 host matching needs its old origin (generic r2.dev recognition remains). `next.config.ts` retains Supabase CSP/remotePatterns and exports R2 public alias; `lib/site-url.ts` retains Vercel fallback. Proposed work: tested owned-origin/key mapping, followed by configuration removal after proof. No media/provider ENVs were removed here.
5. **Release/operations:** checkout placement guard, unverified auth/payment UAT and reconciliation operator closure remain real gates. Raw Redis Error logging deserves sanitized name/code logging before release; no credential leak was proven. Baseline lint is failing, not a pass.
